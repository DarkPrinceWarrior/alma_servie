Детекция изменения притока методом PaAno (AI)

Что такое PaAno Score?

PaAno (Patch-based Anomaly detection) — нейросетевой метод обнаружения аномалий во временных рядах (ICLR 2026).

  1. Обучение на норме. Все нормальные участки данных скважины нарезаются на короткие фрагменты (патчи по 64 точки = 128 мин). 1D-CNN кодирует каждый патч в вектор-эмбеддинг. Из тренировочных эмбеддингов формируется банк нормальных паттернов.
  2. Скоринг. Для каждого фрагмента вычисляется расстояние до ближайших эталонов в банке. Чем дальше — тем выше PaAno Score.
  3. Детекция. Устойчивое превышение порога score фиксируется как начало аномалии.

Особенности для изменения притока: используется патч 64 точки (128 мин) на 2-минутной сетке для ловли медленных трендовых аномалий.

Результат: обнаружено 3 из 3 интервалов аномалий.
