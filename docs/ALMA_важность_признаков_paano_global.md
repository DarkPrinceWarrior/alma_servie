# Важность признаков — детектор `paano_global`

**Дата:** 2026-05-21
**Детектор:** `paano_global` — общий детектор нормальности, проверяемый кандидат на роль основного
**Охват:** все размеченные скважины — 37 случаев (скважина × тип аномалии): негерметичность 5, приток 24, соли 8. 36 уникальных идентификаторов скважин — скважина `3245` размечена и как приток, и как соли.
**Исходные отчёты:** `artifacts/reports/<аномалия>/<аномалия>_paano_global_feature_importance.html`

Балл важности — шкала 0–100. Вычисляется ретроспективно по артефактам детектора (детектор при этом не переобучается) и объединяет три составляющих: физику канала (изменение относительно базового участка до аномалии), связь отклонений канала с оценкой детектора и стабильность сигнала по интервалам.

## 1. Топ-5 признаков (среднее по всем 37 размеченным случаям)

Усреднение по всем трём типам аномалий в одном пуле.

| № | Признак | Балл |
|---|---|---|
| 1 | Давление на приеме насоса | 73.0 |
| 2 | Температура на приёме насоса | 42.5 |
| 3 | Температура масла двигателя (масло ПЭД) | 38.6 |
| 4 | Выходной ток ПЧ | 35.5 |
| 5 | Токи по фазам A / B / C | 28.9 / 28.1 / 28.1 |

Места 5–7 занимают три фазных тока — их баллы статистически неразличимы, поэтому рассматриваются как одно семейство признаков. Сразу за топ-5 идут Cos Ф (27.0) и Коэффициент загрузки ПЭД (26.8).

Общий топ-5 смещён в сторону притока, так как на него приходится 24 из 37 случаев. По-настоящему универсальный признак ровно один — давление на приёме насоса (№1 во всех трёх типах).

## 2. Профиль важности по типам аномалий (отдельно по каждому классу)

| Аномалия | Картина важности |
|---|---|
| Негерметичность (5 случаев) | Откликается почти весь набор каналов: давление 88.7, температура масла 82.1, выходной ток ПЧ 78.3, температура на приёме 75.9, фазные токи ~73, загрузка ПЭД 71.2. Резкое событие даёт широкий многоканальный отклик. |
| Приток (24 случая) | Один доминирующий канал — давление на приёме 75.3. Далее резкий обрыв: температура на приёме 39.7, остальные каналы ниже 30. Практически одноканальная картина. |
| Соли (8 случаев) | Размытый многоканальный профиль: давление 56.6, выходная частота 39.8, температура масла 39.0, фазные токи 33–37, выходной ток ПЧ 34.2, загрузка ПЭД 32.5. |

## 3. Загрузка ПЭД («Коэффициент загрузки ПЭД») — вердикт

Эксперт просил проверить канал отдельно: если он не несёт влияния — считать его бесполезным.

**Канал не бесполезен.** Влияние есть, но оно условное и зависит от типа аномалии:

| Аномалия | Средний балл | Роль |
|---|---|---|
| Негерметичность | 71.2 | сильный, часто ключевой сигнал |
| Соли | 32.5 | умеренный вспомогательный |
| Приток | низкий | практически шум |

Сводно по 37 случаям: средний балл 26.8, общий ранг около 9. Вердикты модели по каналу: ключевой — 6, вспомогательный — 10, шум — 19, модельный суррогат — 2. Реальный сигнал присутствует примерно в 16 случаях из 37.

**Решение: канал оставить.** Удаление потеряет сигнал по негерметичности и солям. В топ-5 канал не входит, но это рабочий признак, а не мусор. Гипотеза «нет влияния — убрать» данными не подтверждается.

## 4. Сверка с экспертным списком

Эксперт назвал ожидаемый топ для всех аномалий: давление на приёме, температура масла ПЭД, токи по фазам.

| Экспертный признак | Результат проверки |
|---|---|
| Давление на приёме | Подтверждено полностью — №1 во всех трёх аномалиях |
| Температура масла ПЭД (= температура масла двигателя) | Подтверждено — стабильно в топ-3 |
| Токи по фазам | Подтверждено частично — сильны для негерметичности, умеренны для солей, для притока почти шум |

Дополнения по результатам анализа:
- Рядом с температурой масла стабильно сильнее работает отдельный канал **«Температура на приёме насоса»** (№2 общего рейтинга) — в экспертный список он не вошёл, но значим.
- Из токовых каналов самый стабильный — **«Выходной ток ПЧ»** (№4 общего рейтинга), а не фазные токи.

Итог: экспертный список корректен для негерметичности и солей; для притока определяющим является только давление на приёме.

## 5. Охват данных, определение типа и методология

**Определение типа аномалии.** Детектор `paano_global` тип аномалии не определяет — он выдаёт только балл «есть отклонение» и момент начала события. Разбиение скважин на негерметичность / приток / соли взято из экспертной разметки: отчёт важности запускался отдельно для каждого типа и грузил соответствующий файл размеченных интервалов (`<тип>_intervals.parquet`). Поэтому раздел 2 — это «среднее по группе скважин, помеченных экспертом этим типом», а не классификация модели. Различимость профилей в разделе 2 — кандидат-«отпечаток» для будущего слоя классификации типа, но пока это наблюдение, а не работающий классификатор.

**Охват и уровни агрегации.** Анализ покрывает **все размеченные скважины каждого класса**, отброшенных нет: негерметичность 5/5, приток 24/24, соли 8/8 (счёт по уникальным скважинам в файлах интервалов). Единица анализа — скважина: если у неё несколько размеченных интервалов (приток — 27 интервалов на 24 скважины, соли — 9 на 8), они сводятся в один профиль важности. Итого 37 случаев «скважина × тип», 36 уникальных идентификаторов скважин. Скважины нормальной работы (`norm_work`) и неразмеченные периоды в анализ **не входят**: методу нужен размеченный интервал, вокруг которого считается важность. То есть это важность «на фоне известной аномалии», а не оценка по всей популяции скважин. Два уровня агрегации:

- раздел 1 (топ-5) — среднее по всем 37 случаям, три типа объединены в один пул;
- раздел 2 — отдельно по каждому типу (5 / 24 / 8 случаев).

**Прочее.**

- Анализ построен только на детекторе `paano_global` (по решению от 2026-05-21 вариант `paano_shared` в этой итерации не рассматривался).
- Отчёты важности признаков пересобраны 2026-05-21, формат сводки версии 2, единая сетка 5min, источник согласован с оценкой детектора.
- Балл важности — ретроспективная оценка, детектор при этом не переобучается.
- Каждый случай «скважина × тип» учитывается один раз; общий рейтинг отражает распределение случаев по типам аномалий.

## 6. Известная проблема: `paano_shared` для negermet и salt

Зафиксировано при выполнении задачи (в этой итерации не исправлялось):

- файлы оценок `paano_shared` для `negermet` и `salt` лежат на удалённых сетках (2min и 15min);
- в `db/` после чистки остались только `negermet=5min` и `salt=10min/5min`;
- список `source_candidates` в `alma_service/anomaly_specs.py` устарел;
- из-за этого регенерация отчётов важности признаков и отчётов детекции для `paano_shared` по negermet/salt завершается ошибкой `No source dataset found`;
- `pritok` согласован, `paano_global` проблемой не затронут.

Варианты устранения: вернуть удалённые сетки повторной сборкой датасетов либо перепрогнать детекцию `paano_shared` на оставшихся сетках с обновлением `source_candidates`.

## 7. Эксперимент: сокращение схемы до топ-7 каналов

Проверка: меняются ли метрики `paano_global` при обучении только на топ-признаках важности.

**Постановка.** Создана сокращённая схема `configs/alma_global_feature_schema_top7.json` — 7 каналов: давление на приёме, температура на приёме, температура масла двигателя, токи фаз A/B/C, Коэффициент загрузки ПЭД. «Выходной ток ПЧ» (№4 по важности) не вошёл — он исключён из схемы глобального детектора по покрытию, детектор его и не использовал. Глобальный энкодер обучен заново на 7-канальной схеме. Для честного сравнения тем же кодом и данными прогнан эталон на полной схеме (21 канал). Оба прогона — без ретюнинга, patch 192/384, сетка 5min, 200 итераций. Эталон на 21 канале воспроизвёл задокументированный baseline бит-в-бит.

| Аномалия | Метрика | 21 канал | 7 каналов | Δ |
|---|---|---|---|---|
| Негерметичность | hit-rate · ложные/сут | 5/5 · 0 | 5/5 · 0 | — |
| | задержка median / p90, ч | 0.05 / 0.72 | 0.05 / 0.72 | бит-в-бит |
| Приток | hit-rate · ложные/сут | 24/24 · 0 | 24/24 · 0 | — |
| | задержка median / p90, ч | 1.60 / 5.33 | 1.72 / 7.43 | +0.12 / +2.1 — хуже |
| Соли | hit-rate · ложные/сут | 8/8 · 0 | 8/8 · 0 | — |
| | задержка median / p90, ч | 1.00 / 12.07 | 1.00 / 11.99 | ≈ |

**Выводы.**

- Качество детекции не изменилось: 7 каналов держат те же 100% попадание и 0 ложных срабатываний по всем трём аномалиям.
- Задержка обнаружения почти не изменилась: негерметичность — бит-в-бит, соли — те же (p90 даже чуть лучше), приток немного медленнее (median +7 мин, p90 +2.1 ч — хвостовой эффект на нескольких интервалах из 24).
- 14 выброшенных каналов не влияют на то, поймана ли аномалия, и лишь слегка — на скорость обнаружения притока. Ранжирование важности признаков подтверждено.

**Воспроизводимость:** схема `configs/alma_global_feature_schema_top7.json`, прогон `scripts/evaluation/benchmark_global_normality_detector.py` с `--feature-schema` и `--no-retune`. Сырые выгрузки бенчмарка не сохранены — метрики в таблице выше.

**Оговорка.** Прогон без ретюнинга порогов. Вариант с ретюнингом порогов прогоняется отдельно — результат будет дописан.

**Выводы.**

**Воспроизводимость:** та же схема и тот же бенчмарк, прогон с ретюнингом порогов. Сырые выгрузки не сохранены — метрики в таблице выше.
